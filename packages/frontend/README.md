# @5dcol/frontend

Browser frontend for 5dcol, built with Vue and Vite.

This package renders the playable web UI, including the main menu, canvas/WebGL
game board, live 5dpgn record panel, cursor navigation, branching and deduction
controls, import/export dialogs, match-room UI, settings, sound, and Vue I18n
integration.

Set `VITE_ASSET_BASE_URL` to load `public/assets` from a CDN or static asset host.
